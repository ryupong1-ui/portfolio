01 / Start with context

A useful first message can be simple.

There is no required brief format. A short description of the project is enough to begin.

PROJECT

What are you building?

A portfolio, business website, product landing page, interactive experiment, or something that does not fit those labels yet.

GOAL

What should the site achieve?

Tell me the action you want visitors to take, the feeling you want them to leave with, or the problem the interface needs to solve.

02 / Typical process

From first message to shipped interface.

The exact workflow changes with the project, but these are the usual stages.

01

Brief

Collect the goal, audience, content, references and constraints so the page has a clear direction.

02

Structure

Map the sections, navigation, calls to action and responsive layout before adding heavy effects.

03

Build + motion

Implement the interface and then layer in interaction, transitions and 3D movement where it adds value.

04

Ship

Check links, routes, desktop/mobile layouts and the final file structure before deployment.
